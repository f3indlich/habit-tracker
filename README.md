# Трекер привычек

PWA-приложение для привычек, задач и целей: привычки с повторами и нормой за день, серии, карточка привычки с графиками,
сводка, заметки к дням, задачи со списками, повторами и напоминаниями, общие списки, цели с шагами, личные записи под PIN.
Работает без интернета и ставится на iPhone, Android и компьютер.

Подробная техническая документация — в папке [`tech-docs/`](tech-docs/README.md).

Сборка не нужна — это статический сайт:

- `index.html` — разметка;
- `styles.css` — стили;
- `app.js` — точка входа: подключает модули и запускает приложение;
- `js/` — ES-модули:
  - основа: `core.js` (константы, даты, настройки устройства), `icons.js` (иконки), `storage.js` (данные, сохранение, статистика), `ui.js` (окна, меню, уведомления на экране), `tabs.js` (нижняя панель и кнопка «+»), `wheel.js` (колёса выбора);
  - привычки: `render.js` (главный экран и карточки), `form.js` (создание и изменение привычек), `plan.js` (норма и выполнение плана), `history.js` (карточка привычки и графики), `summary.js` (сводка по всем привычкам);
  - задачи: `tasks.js` (данные и даты задач), `tasksui.js` (экран задач, списки, форма, календарь), `taskparse.js` (разбор фраз вроде «завтра в 15:00»), `repeat.js` (повторы);
  - цели: `goals.js` (данные и расчёты), `goalsui.js` (экран целей);
  - общие списки: `shared.js` (данные и облако), `sharedui.js` (экран);
  - прочее: `settings.js` (настройки, тема, цвета, установка, имя), `privacy.js` и `lock.js` (личные записи и PIN), `sync.js` (облако и вход), `push.js` (напоминания), `tips.js` (подсказки), `guide.js` (справка);
- `sw.js` — офлайн-режим и уведомления;
- `manifest.webmanifest`, `icons/` — установка на устройство.

Версия приложения (сейчас `3.4c`) указана в `sw.js` (`VERSION`), в `index.html` (`styles.css?v=…`, `app.js?v=…`) и во всех `import` в `app.js` и `js/*.js`. При каждой публикации меняйте её везде одной заменой, например `3.4c` → `3.4d`: иначе установленное приложение может смешать старые и новые файлы. Тест «all modules loaded with app version» проверяет, что метки совпадают.

На сайт публикуется только само приложение: `_config.yml` исключает `tests/`, `supabase/`, SQL-файлы, `README.md`, `demo-data.json`, `docs/` и `tech-docs/`.

## Тесты

```
powershell -ExecutionPolicy Bypass -File tests\run.ps1
```

Команда поднимает локальный сервер, открывает Edge или Chrome без окна и печатает результат всех проверок. Параметр `-Only "plan,summary"` запускает только указанные наборы. Тесты также можно открыть в браузере на локальном сервере (`tests\serve.ps1`, затем http://localhost:8766/tests/).

Те же тесты на движке Safari (WebKit через Playwright, нужен Node.js; при первом запуске Playwright и WebKit скачаются сами):

```
powershell -ExecutionPolicy Bypass -File tests\webkit.ps1
```

Проверить опубликованный сайт: тесты берутся из ветки `main`, а приложение — с сайта. Наборы, которым нужен фрейм или код сервера, при этом пропускаются.

```
powershell -ExecutionPolicy Bypass -File tests\run.ps1 -Live
```

Тесты запускают приложение с параметром `?test`: у него отдельное хранилище, нет облака и уведомлений, поэтому настоящие данные не затрагиваются.

## Синхронизация между устройствами (необязательно)

1. Создайте проект на [supabase.com](https://supabase.com) и выполните `supabase-setup.sql` в SQL Editor.
2. Впишите Project URL и публичный ключ (anon / publishable) в `config.js`. Ключ `service_role` / `secret` туда вписывать нельзя.
3. В Authentication → URL Configuration добавьте адрес этого сайта в Site URL и Redirect URLs.

Пока `config.js` пустой, данные хранятся только в браузере на устройстве.

## Напоминания (push-уведомления)

1. Выполните `supabase-push.sql` в SQL Editor.
2. Создайте Edge Function `send-reminders` с кодом из `supabase/functions/send-reminders/index.ts` и выключите у неё проверку JWT.
3. Добавьте секреты функции: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`, `CRON_SECRET`.
4. Запланируйте вызов функции каждые 5 минут через `pg_cron` с заголовком `x-cron-secret`.
5. Публичный VAPID-ключ впишите в `config.js` (`vapidPublicKey`).

На iPhone уведомления работают только в приложении, добавленном на экран «Домой» (iOS 16.4+).

`demo-data.json` — пример данных за год для проверки (Настройки → Данные → Импорт). На сайт он не публикуется: импортируйте его из репозитория.
