# Трекер привычек

Простое PWA-приложение для ежедневных привычек: разовые и с повторами за день, серии, история с графиками,
свои типы привычек, архив. Работает без интернета и ставится на iPhone, Android и компьютер.

Сборка не нужна — это статический сайт:

- `index.html` — разметка;
- `styles.css` — стили;
- `app.js` — точка входа: подключает модули и запускает приложение;
- `js/` — ES-модули: `core.js` (константы, даты, настройки устройства), `icons.js` (иконки), `storage.js` (данные, сохранение, статистика), `ui.js` (окна, меню, уведомления на экране), `render.js` (главный экран и карточки), `form.js` (создание и изменение привычек), `history.js` (история и графики), `settings.js` (настройки, тема, установка, имя), `sync.js` (облако и вход), `push.js` (напоминания);
- `sw.js` — офлайн-режим и уведомления;
- `manifest.webmanifest`, `icons/` — установка на устройство.

Версия приложения (сейчас `1.00a`) указана в `sw.js` (`VERSION`), в `index.html` (`styles.css?v=…`, `app.js?v=…`) и во всех `import` в `app.js` и `js/*.js`. При каждой публикации меняйте её везде одной заменой, например `1.00a` → `1.01a`: иначе установленное приложение может смешать старые и новые файлы. Тест «all modules loaded with app version» проверяет, что метки совпадают.

На сайт публикуется только само приложение: `_config.yml` исключает `tests/`, `supabase/`, SQL-файлы, `README.md` и `demo-data.json`.

## Тесты

```
powershell -ExecutionPolicy Bypass -File tests\run.ps1
```

Команда поднимает локальный сервер, открывает Edge или Chrome без окна и печатает результат всех проверок. Тесты также можно открыть в браузере на локальном сервере (`tests\serve.ps1`, затем http://localhost:8766/tests/).

Проверить опубликованный сайт: тесты берутся с локального сервера, а приложение — с сайта.

```
powershell -ExecutionPolicy Bypass -File tests\run.ps1 -App https://f3indlich.github.io/habit-tracker/
```

Тесты запускают приложение с параметром `?test`: у него отдельное хранилище, нет облака и уведомлений, поэтому настоящие данные не затрагиваются.

## Синхронизация между устройствами (необязательно)

1. Создайте проект на [supabase.com](https://supabase.com) и выполните `supabase-setup.sql` в SQL Editor.
2. Впишите Project URL и публичный ключ (anon / publishable) в `config.js`. Ключ `service_role` / `secret` туда вписывать нельзя.
3. В Authentication → URL Configuration добавьте адрес этого сайта в Site URL и Redirect URLs.

Пока `config.js` пустой, данные хранятся только в браузере на устройстве.

## Напоминания (push-уведомления)

1. Выполните `supabase-push.sql` в SQL Editor.
2. Создайте Edge Function `send-reminders` с кодом из `supabase/functions/send-reminders/index.ts` и выключите у неё проверку JWT.
3. Добавьте секреты функции: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`, `CRON_SECRET`.
4. Запланируйте вызов функции каждые 5 минут через `pg_cron` с заголовком `x-cron-secret`.
5. Публичный VAPID-ключ впишите в `config.js` (`vapidPublicKey`).

На iPhone уведомления работают только в приложении, добавленном на экран «Домой» (iOS 16.4+).

`demo-data.json` — пример данных за год для проверки (Настройки → Данные → Импорт). На сайт он не публикуется: импортируйте его из репозитория.
