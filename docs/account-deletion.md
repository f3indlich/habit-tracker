# Удаление аккаунта по письму

Запасной способ для тех, у кого не получается удалить аккаунт в приложении (Настройки → Аккаунт → Удалить аккаунт).

## 1. Проверка запроса

- Принимать запрос только с адреса, к которому привязан аккаунт.
- Если письмо пришло с другого адреса, ответить: «Чтобы мы могли удалить аккаунт, напишите, пожалуйста, с почты, на которую он зарегистрирован».
- Не удалять по просьбе третьих лиц и не запрашивать дополнительные данные.

## 2. Удаление

1. Supabase → Authentication → Users.
2. Найти пользователя по email.
3. Меню строки → Delete user → подтвердить.
4. Каскадное удаление уберёт строки в habit_data, push_subscriptions и push_log.
5. Проверить в Table Editor (habit_data, push_subscriptions), что строк с этим user_id нет.

## 3. Срок

Не позднее 30 дней с даты получения запроса (ч. 5 ст. 21 152-ФЗ). Лучше — в день получения.

## 4. Ответ пользователю

> Здравствуйте! Ваш аккаунт в «Трекере привычек» и все связанные с ним данные в облаке удалены. Привычки, сохранённые на Ваших устройствах, остались там — их можно удалить в настройках приложения или очисткой данных сайта. Если аккаунт понадобится снова, просто войдите с той же почтой — будет создан новый пустой аккаунт.

## 5. Журнал обращений

Без email и других данных пользователя.

| Дата запроса | Дата удаления | Способ | Примечание |
|---|---|---|---|
| | | письмо / приложение | |

## 6. Резервные копии

Данные пропадают из резервных копий Supabase по мере их устаревания. В политике конфиденциальности это указано так: «из резервных копий — в течение 30 дней».
