# Личные привычки

## Что это

Личные привычки не видны при обычном просмотре. Они появляются в разделе «Личное» внизу списка, только когда приложение открыто PIN-кодом или через Face ID / Touch ID. Открыть его можно долгим нажатием (около 0,6 с) на шестерёнку настроек. Повторное долгое нажатие закрывает раздел. Подсказок об этом жесте в приложении нет.

## От чего защищает

- От взгляда со стороны и от человека, которому дали разблокированный телефон.
- Пока раздел закрыт, названий, иконок, заметок и отметок личных привычек нет в разметке страницы. Скринридер их тоже не видит.
- Личные привычки никогда не учитываются в общей статистике, даже когда раздел открыт: в кольце дня и «N из M», в сериях в шапке, в сводке, в календаре, в наблюдениях, в рейтинге, в архиве, в подсказках.
- Уведомления не содержат названий личных привычек.

## От чего НЕ защищает

Это не шифрование.

- Данные лежат в `localStorage` браузера и в облаке (таблица `habit_data`) в открытом виде, так же как обычные привычки. Человек с доступом к DevTools или к базе данных их увидит.
- Файл экспорта содержит все данные, в том числе личные привычки, и его можно получить без PIN.
- На новом устройстве, где PIN ещё не задан, личные привычки из облака можно открыть, просто задав новый PIN. Это сделано намеренно: PIN хранится только на устройстве.
- Подсказки о жесте нет, но кто знает о функции, найдёт его. Защищает только PIN.

## Как устроен PIN

- От 4 до 6 цифр.
- Сам PIN не хранится. Хранится хэш PBKDF2-SHA256 (WebCrypto) со случайной солью 16 байт и 200 000 итераций. Хэши сравниваются за постоянное время.
- Всё лежит в `localStorage` под ключом `habit-tracker-lock`: `salt`, `iter`, `hash`, `cred` (идентификатор ключа Face ID), `fails` (неверные попытки подряд), `until` (время, до которого ввод заблокирован). В облако этот ключ не синхронизируется.
- После 5 неверных попыток подряд ввод блокируется на 30 секунд, затем на 1, 5 и 15 минут. Счётчик и время блокировки переживают перезагрузку страницы. После верного PIN счётчик сбрасывается.
- Состояние «открыто» хранится только в памяти, в `localStorage` и `sessionStorage` не пишется.

## Face ID / Touch ID

- Включается по желанию после создания PIN, если устройство это умеет (`PublicKeyCredential.isUserVerifyingPlatformAuthenticatorAvailable`). Если не умеет, пункт не показывается.
- Работает через WebAuthn: `navigator.credentials.create` с `authenticatorAttachment: 'platform'` и `userVerification: 'required'`, проверка через `navigator.credentials.get`. Приложение проверяет флаг подтверждения пользователя (UV) в ответе.
- Это только локальная проверка «владелец у телефона». Подпись нигде не проверяется на сервере.
- iOS может сохранить ключ в Связке ключей под нейтральным именем «Трекер привычек».
- PIN всегда остаётся запасным способом.

## Автоблокировка

Раздел закрывается сам:
- сразу при уходе приложения в фон (`visibilitychange` → `hidden`, `pagehide`), чтобы в переключателе приложений не осталось снимка;
- после 2 минут без касаний, клавиш и прокрутки;
- при выходе из аккаунта и при удалении аккаунта.

При блокировке раздел удаляется из DOM синхронно. Открытые история, заметка или форма личной привычки закрываются, их содержимое очищается.

## Забытый PIN

Восстановить PIN нельзя. Единственный путь — «Забыли PIN?» → «Стереть личные привычки» с подтверждением словом «СТЕРЕТЬ». Сбросить PIN по коду из письма нельзя намеренно: у человека с разблокированным телефоном почта обычно открыта там же.

- Удаляются личные привычки с их отметками, пропусками и заметками, а также PIN и ключ Face ID.
- Если выполнен вход в аккаунт, удаление уходит в облако и на все устройства. Лист об этом предупреждает и предлагает сначала скачать копию данных.

## Настройки

Кнопка «⋮» в заголовке открытого раздела «Личное»:
- сменить PIN;
- включить или выключить Face ID / Touch ID;
- отключить личные привычки: сделать их обычными (по умолчанию) или удалить. PIN и ключ удаляются.

## Данные

- Флаг привычки `private: true`. Если поля нет, привычка обычная. `normalize()` оставляет только значение `true`.
- Флаг синхронизируется вместе с привычкой: при трёхстороннем слиянии привычка берётся целиком.
- Экспорт и импорт сохраняют флаг.
- Сделать привычку личной или обычной можно только переключателем «Личная привычка» в форме. Переключатель есть, только пока раздел открыт.

## Уведомления

Функция `supabase/functions/send-reminders` (после изменения её нужно задеплоить вручную):
- если в напоминании только личные привычки: заголовок «Трекер привычек», текст «Пора заглянуть в приложение», `tag: 'habit-private'`, пустой список `ids`;
- если есть и обычные, и личные: в уведомлении только обычные, личные не упоминаются совсем, даже количеством;
- расчёт того, нужно ли напоминание, не изменился;
- нажатие открывает приложение в обычном закрытом виде.

## Чек-лист утечек

| Место | Как закрыто |
|---|---|
| Кольцо дня, «N из M», проценты, кольца дней недели и их подсказки | `activeOn` и `dayProgress` используют `visibleHabits` |
| «⭐ Идеально N дней», конфетти | `perfectStreak` использует только обычные |
| «🔥 Название · N дней» в шапке | лучшая серия выбирается только среди обычных |
| Легенда, пустой экран, блок прогресса | только обычные |
| Граница листания недель | обычные, плюс личные, когда раздел открыт |
| Архив | общий архив только для обычных; архив личных — внутри раздела «Личное» |
| Сводка: плитки, календарь, тепловая карта, наблюдения, «идут вместе», рейтинг, «требует внимания», дни недели | `dayInfo` и начало периода используют `visibleHabits` |
| Тосты: отметка, архив, удаление | для личных без названия: «Привычка: выполнено», «Перенесено в архив» |
| Редактор категорий: счётчик привычек | личные учитываются, только когда раздел открыт |
| Тестовое уведомление | берёт только обычную привычку |
| Отметка из уведомления (`?done=`) | личная привычка при закрытом разделе не отмечается |
| Подсказки и онбординг | только обычные |
| История, заметка, форма | при блокировке закрываются и очищаются |
| Переключатель в форме, раздел «Личное», плашка «Личное открыто» | создаются в DOM только при открытом разделе |
| Push-уведомления | см. раздел «Уведомления» |
| `document.title` | постоянный: «Трекер привычек» |
| Консоль | названия не логируются |
