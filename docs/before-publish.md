# Перед публикацией в main

Что нужно сделать Вам вручную, чтобы опубликовать неопубликованные изменения: бирку пропусков, удаление аккаунта, адаптивность, личные привычки, «план и факт». Изменения в коде лежат в ветке dev. Версия поднимется при команде «публикуй».

## 1. Supabase: функция удаления аккаунта (обязательно, до публикации)

Без неё кнопка «Удалить аккаунт» покажет ошибку.

1. Откройте проект в Supabase → **SQL Editor** → **New query**.
2. Вставьте всё содержимое файла `supabase-delete-account.sql` и нажмите **Run**.
3. Проверьте: **Database → Functions** — в списке есть `delete_my_account`.

Запускать один раз. Повторный запуск безопасен: функция пересоздаётся.

## 2. Supabase: обновить функцию напоминаний (обязательно)

Новый код не показывает названия личных привычек в уведомлениях.

1. Supabase → **Edge Functions** → `send-reminders` → вкладка **Code**.
2. Замените весь код содержимым файла `supabase/functions/send-reminders/index.ts`.
3. Нажмите **Deploy**.
4. Убедитесь, что проверка JWT по-прежнему **выключена** (Settings функции → Verify JWT: off). Секреты (`VAPID_*`, `CRON_SECRET`) и расписание `pg_cron` менять не нужно.
5. Проверка: в **Logs** функции через 5–10 минут нет ошибок, ответы `200`.

Порядок не важен: старая версия приложения с новой функцией работает так же, как раньше.

## 3. Почта для вопросов о данных (по желанию)

В `js/core.js` заполните `PRIVACY_EMAIL = 'ваш@адрес'`. Пока поле пустое, в листе удаления аккаунта не показывается строка «Не получается удалить? Напишите…». Скажите мне адрес — впишу сам.

## 4. Заставки iOS (готово)

Делать ничего не нужно: заставки для всех iPhone и iPad уже в icons/. Список размеров — в `docs/ios-splash.md`.

## 5. Команда «публикуй»

Напишите «публикуй». Я сам:
- закоммичу всё в dev, проверю, что ветки не отстают;
- прогоню все тесты;
- подниму версию (следующая — 1.06a) во всех местах;
- покажу коммит и список файлов и дождусь Вашего «да»;
- солью dev в main и отправлю.

Файлы `supabase-delete-account.sql` и папка `docs/` в репозиторий попадут, но на сайт не публикуются (исключены в `_config.yml`).

## Как сделать привычку личной

Переключатель «Личная привычка» намеренно скрыт, пока личный раздел закрыт: посторонний не должен догадаться, что такая функция есть.

1. **Нажмите и держите шестерёнку настроек** (вверху справа) примерно 0,6 секунды. Обычное короткое нажатие по-прежнему открывает настройки.
2. Первый раз появится лист «Личные привычки»: придумайте PIN из 4–6 цифр и повторите его. Затем можно включить Face ID.
3. Внизу списка появится раздел **«Личное»**, а над прогрессом — плашка «Личное открыто · закрыть».
4. Новая личная привычка — кнопка **«+»** в заголовке раздела «Личное» (переключатель в форме уже включён).
5. Сделать личной существующую привычку — откройте её форму («⋮» → «Изменить») и включите **«Личная привычка»** внизу формы. Выключите — привычка вернётся в обычные.
6. Закрыть раздел — плашка «закрыть», снова долгое нажатие на шестерёнку, сворачивание приложения или 2 минуты без касаний.

Настройки замка (сменить PIN, Face ID, отключить личные привычки) — кнопка «⋮» в заголовке раздела «Личное».

Пока изменения не опубликованы, на сайте https://f3indlich.github.io/habit-tracker/ этого нет. Проверить до публикации можно локально: `powershell -ExecutionPolicy Bypass -File tests\serve.ps1`, затем http://localhost:8766/ (данные там будут свои, отдельно от сайта).

## 6. После публикации — проверка на телефоне

Сайт обновится через 1–2 минуты. В установленном приложении появится «Доступна новая версия» → **Обновить**.

**Удаление аккаунта** (на тестовом аккаунте, не на основном):
- Настройки → «Удалить аккаунт» → введите почту → удаление проходит.
- На втором устройстве с этим аккаунтом приложение выходит из аккаунта и один раз показывает сообщение, привычки остаются.

**Личные привычки** (iPhone, установленное приложение):
- Долгое нажатие (~0,6 с) на шестерёнку → создать PIN → включить Face ID.
- Добавить личную привычку кнопкой «+» в разделе «Личное».
- Свернуть приложение и открыть переключатель приложений: личного раздела на снимке нет.
- Открыть снова: раздел закрыт, общий счётчик «N из M» личные не учитывает.
- Через 2 минуты без касаний раздел закрывается сам.
- Личная привычка с напоминанием: на экране блокировки приходит «Пора заглянуть в приложение», без названия.

**План и факт**:
- Количественная привычка (например, вода, цель 6), несколько дней с отметками.
- Сменить цель на 8 → «С сегодняшнего дня» → прошлые дни остались выполненными, в истории привычки появилась «История целей».
- Снова сменить цель → «Для всей истории» → прошлые дни пересчитались, список целей исчез.
- Сменить цель на двух устройствах → после синхронизации записи истории есть на обоих.

**Адаптивность**:
- Кнопка «Назад» на Android закрывает верхний лист, а не приложение.
- Поле почты при входе не приближает экран на iPhone.
- Крупный системный шрифт: тексты переносятся, ничего не обрезано.

## Если что-то пошло не так

- Кнопка удаления пишет ошибку → не выполнен шаг 1.
- В уведомлении видно название личной привычки → не задеплоен шаг 2.
- Откатить сайт: скажите мне — верну main на предыдущий релиз (1.05a) отдельным коммитом.
