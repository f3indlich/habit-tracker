# 1. Обзор

## Назначение

Персональное прогрессивное веб-приложение (PWA) для привычек, задач и целей на русском языке. Работает без интернета, ставится на экран телефона и компьютера, по желанию синхронизируется между устройствами через Supabase.

Опорное устройство для проверки интерфейса — iPhone 15 Pro (393 × 852 pt).

## Возможности

**Привычки**
- Разовые («да/нет») и количественные (норма за день, шаг, единица измерения).
- Расписание: каждый день, дни недели, N раз в неделю, раз в N недель; пропуски по уважительной причине.
- Нормы, меняющиеся во времени (история норм), выполнение плана с учётом перевыполнения.
- Серии, рекорды, заметки к дням, категории, архив, личные привычки под PIN.
- Карточка привычки: неделя / месяц / год, график по дням со сжатой шкалой выше нормы, дни недели, заметки.
- Сводка по всем привычкам: кольцо выполнения, дни по видам (полные / частичные / пропуски), наблюдения, сравнение с прошлым периодом.

**Задачи**
- Дата, время, срок, напоминания, повторы, подзадачи, важность, «когда-нибудь», архив.
- Списки с цветами, разделы «Когда-нибудь», «Выполненные», «Архив», поиск с фильтрами «Важные», «Со сроком», «Повторяющиеся», «Личные», выбор нескольких задач, перенос.
- Разбор фраз при вводе: «завтра в 15:00», «каждый понедельник», «#дом», «срочно».
- Общие списки с другими пользователями (по коду приглашения).

**Цели**
- Срок, шаги, объём (например, «500 слов»), связь с привычками, темп и прогноз, напоминания.

**Прочее**
- Темы (светлая / тёмная / системная), акцентный цвет, стили иконок (контур, цвет, плитка, эмодзи), режимы анимации.
- Экспорт и импорт данных в JSON.
- Подсказки при первом запуске и справка.

## Технологии

| Слой | Технология |
|---|---|
| Интерфейс | HTML, CSS (переменные, `:has`, `color-mix`), JavaScript ES-модули без сборки |
| Хранение на устройстве | `localStorage` (основное состояние и настройки), Cache Storage (офлайн) |
| Офлайн | Service Worker `sw.js` |
| Облако | Supabase: Postgres + RLS, Auth (вход по ссылке и коду из письма), Realtime, Edge Functions (Deno, TypeScript) |
| Уведомления | Web Push (VAPID) |
| Шрифты | Системный шрифт Apple, иначе Inter (локальный woff2), цветные эмодзи |
| Хостинг | GitHub Pages из ветки `main` |
| Тесты | Собственный набор в браузере; запуск в Edge/Chrome через CDP и в WebKit через Playwright |

Внешняя библиотека в рантайме одна — `@supabase/supabase-js@2.117.0`. Она грузится лениво, только при включённой синхронизации, с проверкой целостности (SRI).

## Ограничения

- Данные на устройстве лежат в `localStorage`, его объём около 5 МБ. При нехватке места пользователь получает предупреждение.
- Объём одной записи в облаке ограничен 5 МБ триггером в базе.
- «Личное» скрывается PIN-кодом, но не шифруется.
- На iPhone push-уведомления работают только у приложения, установленного на экран «Домой» (iOS 16.4+).
- Лимиты данных: до 1000 задач, 12 списков задач, 20 активных и 100 всего целей; подробности — в разделе 3.
