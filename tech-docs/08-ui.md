# 8. Интерфейс

## Экраны

| Экран | Где в коде | Что на нём |
|---|---|---|
| Сегодня (главная) | `render.js` | Шапка с прогрессом дня и чипами серий, полоса недели, ближайшая цель, блок задач, привычки по времени дня или категориям |
| Задачи | `tasksui.js` | Чипы списков, неделя или месяц, группы (просрочено, по дням, без даты, когда-нибудь, выполнено, архив) |
| Цели | `goalsui.js` | Активные и выполненные цели с прогрессом и темпом |
| Настройки | `settings.js` | Профиль, тема, уведомления, анимации, разделы привычек, задач, оформления, данных и справки |
| Сводка | `summary.js` | Окно поверх главной: период, кольцо, дни, наблюдения, привычки |
| Карточка привычки | `history.js` | Окно: серия / рекорд / всего, периоды, план, график, дни недели, заметки |
| Формы | `form.js`, `tasksui.js`, `goalsui.js` | Привычка, задача, цель, список |

Нижняя панель (`tabs.js`): «Сегодня», «Задачи», «Цели», «Настройки» и круглая кнопка «+» с меню «Цель / Задача / Привычка».

## Окна

- Окно (`.overlay` + `.sheet`) открывается `openOverlay`, закрывается `closeOverlay`, крестиком, касанием фона, жестом вниз и клавишей Esc.
- Окна могут открываться поверх других (карточка привычки поверх сводки, карточка списка поверх «Списков»).
- Шапка окна: заголовок, крестик; у форм с кнопкой ✓ крестик слева, заголовок по центру.

## Жесты

| Жест | Где | Действие |
|---|---|---|
| Касание | Кнопка отметки | +1 (или «сделано») |
| Удержание | Кнопка отметки количественной привычки | Выполнить целиком |
| Свайп по карточке | Привычки, задачи | Действия (пропуск, перенос, удаление) |
| Свайп по полосе недели | Главная, задачи | Соседняя неделя (с подглядыванием и доводкой) |
| Свайп по графику | Карточка привычки, сводка | Соседний период |
| Удержание и перетаскивание | Карточки привычек, задачи, списки | Изменить порядок |
| Удержание | Чип списка задач | Меню списка |

Долгое нажатие — 600 мс, допуск сдвига — 10 px.

## Принципы

- **Статичная вёрстка.** Блоки, кнопки и меню не прыгают и не перекрывают друг друга. Высоты зарезервированы, тексты обрезаются, а не раздвигают блоки.
- **Отключать, а не скрывать.** Недоступное действие показывается неактивным с пояснением (например, «Новый список» на пределе в 12 списков).
- **Логичное размещение.** Функции группируются по смыслу, страницы не заполняются ради заполнения.
- **Обращение на «Вы»** с заглавной буквы во всех текстах.
- **Компактность.** Числа и графики занимают ровно столько места, сколько нужно для чтения.

## Дизайн-токены

Цвета задаются CSS-переменными в `:root` и переопределяются для тёмной темы:
`--bg`, `--card`, `--text`, `--muted`, `--faint`, `--border`, `--track`, `--accent`, `--accent-ink`, `--data`, `--warn`, `--danger`, `--good`.

- Акцентный цвет выбирает пользователь.
- `--data` — цвет данных на графиках и в кольцах; «сверх нормы» рисуется им.
- Палитра цветов привычек и списков — 10 цветов (`COLORS` в `core.js`).

Шрифт — одна переменная `--f-ui`: системный шрифт Apple на iPhone и Mac, иначе Inter из `fonts/`. Эмодзи — отдельный набор `--f-emoji`.

## Адаптивность

- Опорная ширина — 393 px (iPhone 15 Pro); проверяется от 320 до 1440 px и в горизонтальной ориентации.
- Учитываются безопасные зоны (`env(safe-area-inset-*)`) и экранная клавиатура (`interactive-widget=resizes-content`).
- Поля ввода не меньше 16 px, чтобы iOS не увеличивал страницу.
- Цели касания не меньше 44 × 44 px.

## Доступность

- У кнопок-иконок есть `aria-label`; переключатели — `role="radio"`/`aria-checked`, `aria-pressed`.
- Окна — `role="dialog"`, `aria-modal`.
- Перестановка доступна с клавиатуры стрелками.
- Контраст текста проверяется в светлой и тёмной теме.

## Анимации

- Режимы в настройках: яркие, спокойные, без анимаций; системная настройка «уменьшить движение» учитывается всегда.
- Перестановки и появление блоков анимируются FLIP-техникой (`flipAfter`).
- Числа (например, «Сделано N из M») анимируются только при изменении в пределах того же периода; при листании периода не переигрываются.
- Анимируются только `transform` и `opacity`, без пересчёта вёрстки.
