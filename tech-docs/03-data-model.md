# 3. Модель данных

Всё состояние пользователя — один JSON-объект `state` (модуль `storage.js`). Он хранится в `localStorage` под ключом `habit-tracker-v1` и целиком синхронизируется с облаком (одна строка таблицы `habit_data`).

## Корневые поля

| Поле | Тип | Назначение |
|---|---|---|
| `habits` | массив | Привычки |
| `log` | `{ "ГГГГ-ММ-ДД": { habitId: число } }` | Отметки: сколько раз выполнено за день |
| `skip` | `{ день: { habitId: 1 } }` | Пропуски по уважительной причине |
| `notes` | `{ день: { habitId: текст } }` | Заметки к дням |
| `categories` | массив `{ id, name }` | Категории привычек (до 40 символов в названии) |
| `tasks` | массив | Задачи |
| `taskLists` | массив `{ id, name, color, updatedAt }` | Списки задач |
| `goals` | массив | Цели |
| `smart` | объект | Настройки умных напоминаний |
| `goalRemind` | объект | Настройки напоминаний о целях |
| `profile` | `{ name }` | Имя для приветствия |

Дни везде записываются ключом `ГГГГ-ММ-ДД` в местном времени устройства.

## Привычка

| Поле | Тип и ограничения | Смысл |
|---|---|---|
| `id` | строка, уникальная | Идентификатор |
| `name` | до 60 символов | Название |
| `target` | 1–10000 (без шага до 100) | Норма за день |
| `step` | ≥1, ≤ target | Сколько добавляет одно нажатие |
| `unit` | до 20 символов | Единица («стаканов») |
| `icon` | ключ из `ICONS` | Иконка; старые эмодзи переводятся в ключи |
| `color` | `#rgb` … `#rrggbbaa` | Цвет |
| `time` | `morning`, `day`, `evening`, `any` | Время дня |
| `days` | массив 0–6 или `null` | Дни недели; `null` — каждый день |
| `schedule` | объект | Расписание «N раз в неделю», «раз в N недель» |
| `goals` | массив `{ until, target, unit, step?, sched? }` | История норм: какая норма действовала до какой даты |
| `remind` | объект | Напоминания |
| `why` | до 120 символов | «Зачем мне это» |
| `cat` | id категории или `null` | Категория |
| `created` | день | Дата создания (начало статистики) |
| `archived` | день | Дата архивации |
| `private` | `true` | Личная привычка (скрыта под PIN) |

## Задача

| Поле | Смысл |
|---|---|
| `id`, `text` (до 200), `note` (до 1000) | Основное |
| `date`, `time` | День и время выполнения |
| `due`, `dueRemind` | Срок и напоминание о сроке |
| `reminds` | Напоминания (до заданного числа) |
| `rep` | Правило повтора (`repeat.js`) |
| `subs` | Подзадачи (до 30 у задачи, до 3000 всего) |
| `list` | id списка; без поля — «Входящие» |
| `important`, `someday`, `ord` | Важность, «когда-нибудь», ручной порядок |
| `done`, `doneAt`, `doneCount`, `lastDone` | Выполнение (у повторяющихся задач — счётчик и последняя дата) |
| `archivedAt`, `private`, `updatedAt` | Архив, личная, время изменения |

Выполненные задачи старше 180 дней удаляются при нормализации.

## Цель

`id`, `title` (до 80), `start`, `due`, `status` (`active`/`done`/`closed`), `steps` (до 30, по 120 символов), `volume` (объём и единица), `habitIds` (до 3 связанных привычек), `note` (до 1000), `completedAt`, `closedAt`.

## Нормализация

`normalize()` вызывается при загрузке, импорте и после слияния с облаком. Она:
- приводит типы, обрезает строки до лимитов, отбрасывает битые записи;
- чинит дубликаты id, проверяет цвета и иконки;
- удаляет отметки несуществующих привычек и нулевые значения;
- убирает у задач ссылки на удалённые списки;
- применяет лимиты количества.

Поэтому любые данные (старый формат, ручной импорт, чужое устройство) после загрузки становятся корректными.

## Лимиты

| Что | Лимит |
|---|---|
| Задачи | 1000 всего (лишние закрытые удаляются первыми) |
| Списки задач | 12, название до 24 символов |
| Подзадачи | 30 у задачи, 3000 всего |
| Цели | 20 активных, 100 всего, 30 шагов, 3 привычки |
| Отметка за день | `MAX_COUNT` |
| Облачная запись | 5 МБ (триггер `habit_data_size_limit`) |

## Ключи `localStorage`

Префикс — `habit-tracker` (в тестах `habit-tracker-test`).

| Ключ | Что хранит |
|---|---|
| `-v1` | Состояние `state` |
| `-theme`, `-accent`, `-icons`, `-view`, `-group`, `-legend-off`, `-data` | Настройки вида |
| `-notify` | Включены ли уведомления |
| `-tasks-*` | Настройки экрана задач (выбранный список, вид, точки, лимит, положение) |
| `-sync-base` | Последняя синхронизированная копия и её версия (для слияния) |
| `-lock` | Хэш PIN и счётчик попыток |

Настройки вида не синхронизируются: у каждого устройства свои.
