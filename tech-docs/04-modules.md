# 4. Модули

Все модули — ES-модули в папке `js/`, подключаются с меткой версии `?v=3.3`. Точка входа — `app.js`.

## Основа

| Модуль | Отвечает за | Зависит от |
|---|---|---|
| `core.js` | Константы, режим тестов, ключи хранилища, даты (`todayKey`, `parseKey`, `addDays`, `weekday`), склонения (`plural`), экранирование (`esc`), цвета, шаблоны привычек, настройки устройства | — |
| `icons.js` | Иконки привычек (`ICONS`: контур + эмодзи, `ICON_ART`: цветные), группы и подсказки иконок по названию, иконки интерфейса `IC` | `core` |
| `storage.js` | `state`, `load`/`save`/`normalize`, расчёты по привычкам: выполнение дня, серии, рекорды, расписание, пропуски | `core`, `icons`, `tasks`, `goals`, `plan` |
| `ui.js` | Окна (`openOverlay`/`closeOverlay`), меню (`openMenu`), подтверждения (`askConfirm`), тосты, анимации FLIP | `core` |
| `tabs.js` | Нижняя панель вкладок и меню кнопки «+» | `ui` |
| `wheel.js` | Колёса выбора чисел и времени | — |

## Привычки

| Модуль | Отвечает за |
|---|---|
| `render.js` | Главный экран: шапка с прогрессом, полоса недели, карточки привычек, виды (список, кольца, сетка), жесты карточек, перестановка |
| `form.js` | Форма создания и изменения привычки, напоминания, шаблоны |
| `plan.js` | Норма на день, выполнение плана за период (в норму / сверх нормы) |
| `history.js` | Карточка привычки: периоды, блок «Сделано N из M», графики, дни недели, заметки; экран дня; подсказки на графиках |
| `summary.js` | Сводка по всем привычкам: виды дней, наблюдения, строки привычек |

## Задачи

| Модуль | Отвечает за |
|---|---|
| `tasks.js` | Нормализация и слияние задач и списков, даты и сроки, группы, точки календаря, напоминания, умные списки |
| `tasksui.js` | Экран задач: чипы списков, неделя и месяц, строки задач и свайпы, форма задачи, экран «Списки» и карточка списка, перенос, выбор нескольких |
| `taskparse.js` | Разбор фраз при вводе (`parseQuick`): даты, время, повторы, срок, важность, тег списка |
| `repeat.js` | Правила повтора: нормализация, следующее повторение, подписи |

## Цели

| Модуль | Отвечает за |
|---|---|
| `goals.js` | Данные целей: прогресс, темп, статусы, слияние |
| `goalsui.js` | Экран целей, форма цели, шаги, связь с привычками |

## Облако и прочее

| Модуль | Отвечает за |
|---|---|
| `sync.js` | Подключение Supabase, вход по ссылке и коду, синхронизация с трёхсторонним слиянием, Realtime, удаление аккаунта |
| `push.js` | Подписка на Web Push, передача часового пояса, обновление подписки |
| `shared.js`, `sharedui.js` | Общие списки: данные из облака, офлайн-копия, экран, приглашения |
| `privacy.js` | Личные записи, PIN (PBKDF2), долгое нажатие (`addLongPress`) |
| `lock.js` | Экран ввода PIN, блокировка по бездействию |
| `settings.js` | Настройки: тема, цвета, иконки, анимации, установка на экран, данные |
| `tips.js` | Подсказки при первом использовании экранов |
| `guide.js` | Справка с демо-примерами |

## Правила

- Модули расчётов (`storage`, `tasks`, `goals`, `plan`, `repeat`, `taskparse`) не обращаются к DOM.
- Связи интерфейсных модулей, которые иначе образовали бы цикл, передаются через хуки (`taskHooks` в `tasksui.js`).
- В коде нет комментариев: имена и структура должны объяснять сами себя, а пояснения живут в этой документации.
- В режиме тестов `app.js` выставляет все экспорты модулей в `window`, поэтому тесты обращаются к функциям напрямую.
