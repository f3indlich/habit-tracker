# 6. Напоминания (Web Push)

## Компоненты

| Компонент | Роль |
|---|---|
| `js/push.js` | Запрашивает разрешение, создаёт подписку через `PushManager` с VAPID-ключом, сохраняет её в `push_subscriptions` вместе с часовым поясом устройства |
| `push_subscriptions` | `endpoint` (PK), `user_id`, ключи `p256dh` и `auth`, `tz`, `user_agent`, `last_seen` |
| `push_log` | Что уже отправлено: `(user_id, habit_id, day)`, PK защищает от повторов |
| `send-reminders` | Серверная функция на Deno, вызывается по расписанию |
| `sw.js` | Показывает уведомление и открывает приложение по нажатию |

## Как работает

1. `pg_cron` каждые 5 минут вызывает функцию с заголовком `x-cron-secret`. Функция сверяет его с секретом за постоянное время, иначе отвечает 403.
2. Функция под сервисным ключом читает подписки и данные пользователей.
3. Для каждого пользователя берётся часовой пояс самой свежей подписки и вычисляется местное время.
4. Определяются уведомления, которые пора отправить:
   - напоминания привычек по их времени и дням, если привычка ещё не выполнена;
   - умные напоминания (вечернее «осталось N» и повтор), если они включены;
   - сроки и напоминания задач;
   - напоминания о целях.
5. Перед отправкой в `push_log` вставляется ключ отправки. Если такой ключ уже есть, вставка не проходит и уведомление не дублируется даже при параллельных вызовах.
6. Уведомление отправляется на все подписки пользователя. Подписки, которые сервис push пометил несуществующими, удаляются.

## Приватность

Личные привычки и задачи не раскрываются в тексте уведомления: вместо названия приходит общий текст («Пора заглянуть в приложение»).

## Настройка

1. Выполнить `supabase-push.sql`.
2. Создать Edge Function `send-reminders` из `supabase/functions/send-reminders/index.ts`, отключить у неё проверку JWT.
3. Задать секреты: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`, `CRON_SECRET` (сервисный ключ Supabase доступен функции сам).
4. Запланировать вызов каждые 5 минут через `pg_cron`.
5. Публичный VAPID-ключ вписать в `config.js`.

## Ограничения платформ

- iPhone: только у приложения, установленного на экран «Домой», iOS 16.4+.
- Точность — до 5 минут из-за шага расписания.
- Без облака (пустой `config.js`) уведомлений нет.
